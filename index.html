🧱 أوامر HTML ودلالاتها🧱 HTML Tags & Meanings

HTML هي لغة ترميز النصوص (HyperText Markup Language) وهي الهيكل الأساسي لأي صفحة ويب. الأمر يُكتب بين قوسين شاربين هكذا: <tag> ويُغلق بشرطة مائلة: </tag>. HTML (HyperText Markup Language) is the skeleton of every web page. A tag is written between angle brackets <tag> and closed with </tag>.

index.html
<!-- أول أمر في أي صفحة HTML -->
<!DOCTYPE html>
<html lang="ar">
  <head>
    <meta charset="UTF-8">
    <title>صفحتي الأولى</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>مرحبًا بالعالم</h1>
    <p>هذه أول فقرة لي.</p>
  </body>
</html>

🎨 أوامر CSS وخصائصها🎨 CSS Commands & Properties

CSS هي لغة تنسيم الصفحات (Cascading Style Sheets) وهي التي تمنح الموقع شكله وألوانه وحركته. تتكون من مُحدِّد (selector) وخاصية وقيمة بين قوسين معقوفين. CSS (Cascading Style Sheets) styles the page — its colors, layout and motion. It consists of a selector, a property and a value inside curly braces.

style.css
/* Selector { Property: Value; } */
h1 { color: #6ea8fe; font-size: 32px; }

.card { background: #0f1533; padding: 20px; border-radius: 16px; }
#main { margin: auto; max-width: 1100px; }
a:hover { color: orange; }      /* عند مرور الفأرة */
.box > p { line-height: 1.8; }     /* ابن مباشر */

🕰️ تأسيس وتطوير لغات البرمجة🕰️ The Story of Programming Languages

لغة البرمجة هي مجموعة قواعد وأوامر تُ下达 للحاسوب لتنفيذ مهمة معينة. مرّت لغات البرمجة بخمسة أجيال من أبسط شكل (أرقام الآلة) إلى أبسط شكل على الإنسان (الأوامر الطبيعية). A programming language is a set of rules and commands that tell the computer what to do. It evolved through five generations — from raw machine numbers to human-like commands.

1

الجيل الأول1st Generation

1940s

لغة الآلة (Machine Language): أرقام ثنائية 0 و1 فقط يفهمها المعالج مباشرة. تحتاج إلى عالم في الفيزياء وتكلف وقتًا طويلًا.Machine Language: only 0 and 1 understood directly by the CPU. Extremely hard and slow to write.

10110000 01100001

2

الجيل الثاني2nd Generation

1950s

لغات التجميع (Assembly): استُبدلت الأرقام برموز مختصرة مثل MOV و ADD، مع وجود برنامج مُجمِّع (Assembler) يحوّلها للآلة.Assembly: binary replaced by short mnemonics (MOV, ADD) converted by an Assembler.

MOV AL, 61h

3

الجيل الثالث3rd Generation

1957 → الآن

لغات من المستوى العالي: Fortran و C و Python و Java و JavaScript — قريبة من الإنجليزية، تعمل على أي حاسوب، وتطوّرت منها معظم لغات اليوم.High-level languages: Fortran, C, Python, Java, JavaScript — English-like, portable, the base of most modern languages.

print("Hello")

4

الجيل الرابع4th Generation

1980s →

لغات من المستوى الممتاز (4GL): مثل SQL و PHP و HTML — موجهة لغرض معين كالقواعد بيانات وتطبيقات الويب، أقل كودًا وأسرع إنجازًا.4GL: SQL, PHP, HTML — purpose-built for databases and web apps, less code, faster results.

SELECT * FROM students;

5

الجيل الخامس5th Generation

2000s →

لغات الذكاء الاصطناعي: تعتمد على معالجة الطبيعة البشرية والاستدلال مثل Prolog و Python (مكتبات AI) وأدوات التعلم الآلي الحديثة.AI languages: natural-language processing and reasoning — Prolog, Python AI libraries and modern ML tools.

model.predict(data)

أهم المحطات في تأسيس اللُّغاتMilestones in Language History

1843

أدا لوفلايس — أول خوارزميةAda Lovelace — first algorithm

وضعت أول خوارزمية مبرمجة لآلة تحليلية (محرك باباج)، وتعتبر أول مبرمجة في التاريخ.Wrote the first algorithm for Babbage's Analytical Engine — the first programmer in history.

1957

Fortran

أول لغة من المستوى العالي ناجحة، صممها جون باكوس في IBM، وكانت للحسابات العلمية.The first successful high-level language, by John Backus at IBM, for scientific computing.

1959

COBOL

صُممت للغة إنجليزية بسيطة لتطبيقات الأعمال والبنوك، ولا تزال تُستخدم حتى اليوم في الأنظمة القديمة.English-like business language — still used today in banking legacy systems.

1972

C

أنشأها دينيس ريتشي في مختبلات بيل (Bell Labs)، وهي أم اللغات: منها اشتُقت C++ و Java و Python و PHP.Created by Dennis Ritchie at Bell Labs — the mother of C++, Java, Python and PHP.

1980

C++

أضافها بيارن ستروستروب مفهوم البرمجة الكائنية (OOP) إلى لغة C.Bjarne Stroustrup added Object-Oriented Programming to C.

1991

Python & HTML & PHP

غيدو فان روسوم أطلق Python (سهولة ووضوح)، و tim berners-lee وضع HTML لشبكة الويب، و PHP لصفحات الويب التفاعلية.Guido van Rossum released Python; Tim Berners-Lee created HTML for the Web; PHP arrived for dynamic pages.

1995

Java & JavaScript & CSS

Java (جيمس جوسلنج) لكتابة برامج تعمل في أي نظام، و JavaScript (بريندان إيش) لتزيين صفحات الويب، و CSS (بيرن لي) لتنسيقها — وهي ثلاثتنا الأساسية في هذا الموقع!Java (James Gosling) — write once, run anywhere; JavaScript (Brendan Eich) for web behavior; CSS (Håkon Wium Lie) for styling — our core trio!

2000

C#

لغة مايكروسوفت التنافسية لتطوير تطبيقات Windows والألعاب عبر Unity.Microsoft's language for Windows apps and Unity games.

2009

Go

لغة جوجل للأنظمة السحابية والشبكات، بسيطة وسريعة جدًا.Google's cloud & networking language — simple and very fast.

2010

Rust

لغة Mozilla للأمان والأداء العالي، تحصد لقب "الأكثر إعجابًا" بين المبرمجين سنويًا.Mozilla's safety-first language — most admired language year after year.

2012

TypeScript

مايكروسوفت أضافت أنواع البيانات (Types) إلى JavaScript لتصبح أكبر لغات الويب.Microsoft added static types to JavaScript — now the backbone of large web apps.

2014 →

Kotlin · Swift · Dart

لغات حديثة لتطبيقات الموبايل (Kotlin لأندرويد، Swift لآيفون، Dart لـ Flutter) تركز على الأمان وسرعة التطوير.Modern mobile languages: Kotlin (Android), Swift (iOS), Dart (Flutter) — safe and fast to build with.

💡 الفكرة الأهم: كل لغة جديدة لم تُلغِ التي قبلها، بل وُلدت لحل مشكلة محددة: C للسرعة، Python للسهولة، JavaScript للويب، Swift للجوال. اختر اللغة حسب مشروعك! 💡 Key idea: each new language was born to solve a specific problem — C for speed, Python for simplicity, JavaScript for the web, Swift for mobile. Pick the language that fits your project!

🧭 خطوات تنفيذ أي مشروع🧭 Steps for Any Project

  1. التحليل والتصميم:Analyze & design: ارسم صفحاتك ورقيًا أولًا: ما القسم يحتوي؟ ما الألوان والخطوط؟Sketch your pages on paper first: sections, colors and fonts.
  2. بناء الهيكل HTML:Build the HTML structure: أنشئ الملف index.html واكتب الأوامر من الأهم للأهم: header ثم sections ثم footer.Create index.html and write tags top-down: header, sections, footer.
  3. التنسيق بـ CSS:Style with CSS: أنشئ style.css وابدأ بالمتغيّرات ثم الخطوط والألوان ثم التخطيط Flex/Grid.Create style.css: variables first, then fonts, colors, then Flex/Grid layout.
  4. الحركة والأنيماشن:Add motion: أضف transition و hover و @keyframes لتجعل الموقع حيًّا — بدون JavaScript.Add transition, hover and @keyframes to bring it to life — no JavaScript.
  5. التجربة والاختبار:Test: جرّب على المتصفح وعلى الموبايل، صحّح الأخطاء، وتأكد من عمل كل الرابطات.Test on desktop and mobile, fix errors and check every link.
  6. النشر والتسليم:Publish & submit: انشر الموقع على GitHub Pages وأرسل رابطه + الملفات المضغوطة للمعلّم.Publish on GitHub Pages and send the link + zipped files to the teacher.

🌍 عرض موقعك على GitHub مجانًا🌍 Show Your Site on GitHub (Free)

GitHub Pages يحوّل ملفاتك إلى موقع حقيقي على الإنترنت برابط دائم — كل ذلك مجانًا وبخمس خطوات فقط. GitHub Pages turns your files into a real website with a permanent link — free, in just 5 steps.

  1. 1. أنشئ حسابًا:Create an account: من github.com/signup (مجاني تمامًا).from github.com/signup (completely free).
  2. 2. أنشئ مستودعًا (Repository):Create a repository: اضغط New repository وسمِّه مثل: razan-ict-website واختر Public ثم Create repository.Click New repository, name it e.g. razan-ict-website, choose Public, then Create repository.
  3. 3. ارفع الملفات:Upload files: اضغط uploading an existing file واسحب ملف index.html ومجلد css و README.md ثم Commit changes.Click uploading an existing file, drag index.html, the css folder and README.md, then Commit changes.
  4. 4. فعّل GitHub Pages:Enable GitHub Pages: من Settings ← Pages: اختر Deploy from a branch ← main ← / (root) ← Save.From Settings ← Pages: choose Deploy from a branch ← main ← / (root) ← Save.
  5. 5. احصل على رابطك:Get your link: بعد دقيقة أو دقيقتين يصبح موقعك على الإنترنت:After 1–2 minutes your site is live at:
    https://YOUR-USERNAME.github.io/razan-ict-website/
✅ لتعديل الموقع لاحقًا: افتح المستودع ← اضغط index.html ← زر ✏️ تعديل ← عدّل الكود ← Commit changes، وينعكس التغيير خلال دقيقة. ✅ To edit later: open the repo → click index.html → ✏️ edit → change the code → Commit changes. The update goes live within a minute.
