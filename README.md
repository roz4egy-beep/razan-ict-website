An interactive educational website for ICT students containing:

| تبديل عربي/إنجليزي + 5 ألوان للخلفية | Arabic/English switch + 5 background colors |

### ✨ المميزات التقنية / Technical Highlights

- **بدون أي JavaScript** — كل شيء HTML + CSS فقط (نفس مهارة المادة!)
- **كل الأنيماشن CSS فقط**: keyframes + hover + transition + scroll-driven animations (`animation-timeline: view()`)
- **أنيماشن مستوحاة من صفحة OmniRoute**: خلفية متدرّجة متحركة، شبكة متحركة، شارات متوهجة، بطاقات بتوهج، شريط كود متحرك، وكتابة آلية للكود
- **إمكانية تغيير ألوان الخلفية** (5 ثيمات) — بـ CSS فقط عبر `radio` inputs
- **عربي / إنجليزي** مع دعم RTL و LTR — بـ CSS فقط عبر `checkbox`
- متجاوب مع الموبايل، ويحترم `prefers-reduced-motion` للوصولية

- **Zero JavaScript** — pure HTML + CSS only
- **All animations are CSS-only**: keyframes, hover, transition and scroll-driven animations
- **Animations inspired by the OmniRoute page**: animated gradient, moving grid, glowing badges, code ticker, typing effect
- **Background color switcher** (5 themes) — CSS only
- **Arabic / English** with RTL & LTR support — CSS only
- Mobile responsive and respects `prefers-reduced-motion`

## 🌍 عرض الموقع على GitHub (مجاني) / Publish on GitHub Pages

### الطريقة من المتصفح (الأسهل) — Via the GitHub website (easiest)

1. **أنشئ حسابًا** على <https://github.com/signup> (مجاني).
2. **أنشئ مستودعًا جديدًا** (New repository):
   - الاسم مقترح: `razan-ict-website`
   - اختر **Public** ← **Create repository**
3. **ارفع الملفات** — اضغط `uploading an existing file` ثم اسحب:
   - `index.html`
   - مجلد `css` (بداخله `style.css`)
   - `README.md`
   - ثم **Commit changes**
4. **فعّل GitHub Pages** — من **Settings ← Pages**:
   - Source: **Deploy from a branch**
   - Branch: **main** ← **/ (root)**
   - **Save**
5. **رابط موقعك** (يظهر بعد دقيقة أو دقيقتين من تبويب Settings ← Pages):

```
https://YOUR-USERNAME.github.io/razan-ict-website/
```

### للتعديل لاحقًا / To edit later

افتح الملف في المستودع ← زر **✏️ تعديل** ← عدّل الكود ← **Commit changes**، وينعكس التغيير خلال دقيقة.

Open the file in the repo → **✏️ edit** → change code → **Commit changes**. The site updates within a minute.
